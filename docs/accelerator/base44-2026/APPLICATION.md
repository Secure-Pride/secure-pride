## Positioning

**Security infrastructure for people who cannot fail safely.**

Secure Pride is building practical, open-source security tools for LGBTQ+ organizations. The accelerator project is a security operations desk modeled on the workflow in [mazze93/touchstone](https://github.com/mazze93/touchstone), adapted to nonprofit partnerships, risk assessment, remediation, and evidence review.

The first use is a significant internal tool for Secure Pride: partner intake → scoped engagement → finding → assigned fix → evidence review → closure or explicit unresolved status. A public demonstration must contain fictional data only. Client records, identities, credentials, attack payloads, and private evidence remain outside the demo.

### What are you building?
I’m building Secure Pride, a cybersecurity nonprofit for LGBTQ+ organizations where a privacy failure can expose identity, interrupt care, or undermine trust. Today, our public tools include a manual text scanner with documented limitations and a draft guide to certificate-based Wi-Fi. The next product is a security operations desk modeled on my Touchstone project: partner intake, scoped engagements, prioritized findings, assigned fixes, evidence review, and governance checks. It will help Secure Pride coordinate support without placing client records or attack payloads in a shared dashboard. The Base44 prototype will demonstrate the workflow using fictional data. I want to validate whether this approach helps small teams complete meaningful security improvements and understand what remains unverified.
